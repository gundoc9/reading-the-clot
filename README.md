# Reading the clot

A teaching app on the TEG and ROTEM trace for anaesthetists: the normal trace beside the abnormal one, one coagulation defect per card, with the treatment the published sources attach to that defect and the trigger they quote for it.

- Seventeen cards in three sections: the trace, the defects, the evidence.
- Every trace is computed by a small model from published medians and thresholds; none is a recording. Drawn values with no published number are labelled ILLUSTRATIVE.
- Every source is named on the card and listed in SOURCES.md with what was read and a link to the paper.
- Nothing leaves the device: one HTML file with its two typefaces embedded, nothing fetched from elsewhere, no tracking.

This is a recognition aid. It is not a transfusion algorithm and reference ranges are set locally.

Files: `index.html` (the app), `clot-icon-180.png` (home-screen icon), `reading-the-clot-card.png` (link preview), `SOURCES.md`, `LICENSE`.
